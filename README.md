# EverShop

Simple e-commerce app built with React, React Router, and Css Modules. Deploys to Netlify.

## Quick Start

npm install
npm start #http://localhost:3000
npm build # outputs to build/

Tech
React (CRA) · React Router · Css Modules · Context API (cart)

Env
REACT_APP_API_URL=https://v2.api.noroff.dev/online-shop
REACT_APP_STORE_NAME=EverShop

Structure
src/{components,pages,context,styles} App.jsx index.jsx

Netlify (SPA)
public/_redirects
/*   /index.html   200
